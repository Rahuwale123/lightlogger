Flask integration

Flask's own app.logger propagates to the root logger by default, so if you just call lightlogger.start(), Flask's built-in request logging already shows up with zero extra wiring. For structured, color-coded request/response lines instead, add a small before_request / after_request pair.

1. Start lightlogger once

Call it in your application factory, before returning the app:

from flask import Flask

import lightlogger


def create_app():
    lightlogger.start()

    app = Flask(__name__)

    # ... register blueprints, config, etc.

    return app

start() is a no-op if it's already running, so this is safe even if create_app() is called more than once (as some test setups do).

2. Log every request with before/after hooks

Stash a start time on flask.g (request-scoped, so there's no shared state between concurrent requests) in before_request, then log the outcome in after_request:

import time

from flask import g, request

import lightlogger


@app.before_request
def _lightlogger_start_timer():
    g.lightlogger_start = time.perf_counter()


@app.after_request
def _lightlogger_log_request(response):
    duration_ms = (time.perf_counter() - g.lightlogger_start) * 1000
    lightlogger.request(request.method, request.path, response.status_code, duration_ms)
    return response

after_request hooks must return the response object — Flask passes it straight through, so the middleware only observes it.

How the log level is chosen

lightlogger.request(method, url, status, duration_ms) derives its level from the status code, not something you set yourself:

Status codeLevel
< 400info
4xxwarn
5xxerror

This status→level mapping shipped in v0.1.1. On earlier versions, request() always logged at info — upgrade to get failed requests rendered as warnings/errors automatically.

Full example

import time

from flask import Flask, g, request

import lightlogger


def create_app():
    lightlogger.start()

    app = Flask(__name__)

    @app.before_request
    def _lightlogger_start_timer():
        g.lightlogger_start = time.perf_counter()

    @app.after_request
    def _lightlogger_log_request(response):
        duration_ms = (time.perf_counter() - g.lightlogger_start) * 1000
        lightlogger.request(request.method, request.path, response.status_code, duration_ms)
        return response

    @app.route("/")
    def index():
        lightlogger.info("index route hit")
        return {"status": "ok"}

    return app
