FastAPI integration

lightlogger has no framework-specific middleware built in — it doesn't need one, since it just watches Python's root logger. But request/response logging is common enough that it's worth a full example: start the dashboard once, and log every request with lightlogger.request().

1. Start lightlogger once

Use FastAPI's lifespan context manager so the dashboard starts when the app starts, and (optionally) stops cleanly on shutdown:

from contextlib import asynccontextmanager

from fastapi import FastAPI

import lightlogger


@asynccontextmanager
async def lifespan(app: FastAPI):
    lightlogger.start()
    yield
    lightlogger.stop()


app = FastAPI(lifespan=lifespan)

For a quick script or notebook, calling lightlogger.start() once at import time works just as well — start() is a no-op if it's already running, so there's no harm in being defensive about it.

2. Log every request with a middleware

A @app.middleware("http") function wraps every request. Time it, call call_next, then log the result on the way out:

import time

from fastapi import Request


@app.middleware("http")
async def log_requests(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)
    duration_ms = (time.perf_counter() - start) * 1000
    lightlogger.request(request.method, request.url.path, response.status_code, duration_ms)
    return response

That's the whole integration. Every request now shows up in the dashboard as a single line, color-coded by status code.

How the log level is chosen

lightlogger.request(method, url, status, duration_ms) derives its level from the status code you pass it — you don't choose it yourself:

Status codeLevel
< 400info
4xxwarn
5xxerror

This status→level mapping shipped in v0.1.1. In earlier releases, request() always logged at info regardless of status code — if you're on an older version, upgrade to get failed requests showing up as warnings/errors in the dashboard automatically.

Full example

import time
from contextlib import asynccontextmanager

from fastapi import FastAPI, Request

import lightlogger


@asynccontextmanager
async def lifespan(app: FastAPI):
    lightlogger.start()
    yield
    lightlogger.stop()


app = FastAPI(lifespan=lifespan)


@app.middleware("http")
async def log_requests(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)
    duration_ms = (time.perf_counter() - start) * 1000
    lightlogger.request(request.method, request.url.path, response.status_code, duration_ms)
    return response


@app.get("/")
async def root():
    lightlogger.info("root endpoint hit")
    return {"status": "ok"}
